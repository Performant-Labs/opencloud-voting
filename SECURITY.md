# Security Policy

## Supported Versions

We only support the latest version of Feature Voting. Please ensure you are running the most recent release.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

**DO NOT open a public issue** for security vulnerabilities.

If you discover a security-related bug, please report it privately by sending an email to **andre@performantlabs.com** (or your preferred security contact). 

We will acknowledge your report within 48 hours and provide a timeline for a resolution. Once a fix is verified, we will release a new version and credit you for the discovery (if desired).
